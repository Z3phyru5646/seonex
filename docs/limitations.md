# Limitations

- v0.1 scores page similarity; it does not establish keyword cannibalization or model Google ranking systems.
- Sentence-transformer results depend on a successful model installation and first download.
- The crawler is sequential and deliberately constrained to authorised single-origin sites.
- There is no WordPress site, domain, VPS, Cloudflare configuration, SSL, GA4, Search Console, schema implementation, or verified backlink in this repository.
- Search intent, recommendations, human review, snapshot comparisons, labels, and evaluation metrics are planned future features.
