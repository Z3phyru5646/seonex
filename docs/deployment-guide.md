# WordPress deployment guide

**Status:** Prerequisites only — no deployment has been performed.

Before deployment, provide or purchase under your own account:

1. A VPS with a supported Linux distribution and firewall access.
2. A registered domain you control.
3. Cloudflare access for the domain, if Cloudflare DNS is required by the course.
4. A backup location and a WordPress administrator email.

After explicit approval, the deployment should use a hardened web server, database credentials stored outside Git, HTTPS via a valid certificate, restrictive firewall rules, and a verified backup. DNS, server installation, and public exposure are manual approval points because they can create costs and affect live infrastructure.
