# Project overview

**Updated:** 22 October 2026

SEONEX is an explainable SEO diagnostic project. The current v0.1 application crawls an authorised site, extracts visible SEO features, measures TF-IDF and optional semantic similarity, and presents page pairs for human review. It does not claim to reproduce Google's systems or confirm cannibalization.

The assessed website and the analysis application are deliberately separate concerns. The checked-in `website/` directory is a static demonstration target for local scanner testing, **not** a WordPress deployment.

## Current state

- SEONEX scanner: implemented and locally tested.
- Demonstration content site: implemented as static HTML for repeatable crawler verification.
- WordPress, VPS, domain, Cloudflare, SSL, GA4, Search Console and backlinks: not configured or claimed.
